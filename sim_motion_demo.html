BEHIND THE MOTION

每个动作，都有对应的计算。

全流程使用同一份三方向、每方向三相位、无噪声的模拟数据。先固定方向 1 解释解混，再汇合其余方向。从九帧观测估计照明波矢、相位和调制度，再用这些结果正式解混；OTF 由成像模型提供。图像与 FFT 来自现有重建核心。

参数从哪里来？为什么是 60.3°？

本动画从同一批九帧实际估计参数，并将结果用于重建。模拟采集时指定照明以生成图像；估计器只读取相机像素和已知的相对相移、OTF 配置。方向 2 的 60.3° 由估计波矢换算而来，不表示估计误差为 0.3°。

理想的 60°、同模长 8 的波矢应为 (4, 4√3)，其 y 分量约 6.928。这里改用整数格 (4, 7)，使周期边界上的频带可精确搬移，避免分数格插值；代价是角度与波矢模长略有不同。表中角度按本页坐标系计算，表示条纹的法线方向；条纹线条本身与波矢垂直。

当前主线的计算顺序是：九帧采集 → 临时分离与频带相关 → 估计波矢、相位、调制度 → 用这些参数正式解混 → 归位 → OTF 融合。波矢决定往哪里搬，相位决定怎样消去其他来源，调制度决定补偿多少幅度；OTF 则需由系统标定或模型提供。

为什么不直接用实验前预设的 m、φ 和 k？

预设值描述希望产生的条纹，重建模型需要的是拍摄时样品处实际形成的条纹。两者是否一致，取决于光路与标定是否准确、采集时是否稳定；不能仅凭“已经设定”就认定它们相等：

调制度 m：两束光到达样品时的强度比例、偏振匹配程度决定干涉反差。即使预设高反差，实际光束强度不平衡或偏振不匹配，条纹反差也会降低。

相位 φ：相移命令规定每次改变多少相位，但样品处的相位起点还包含实际光程差带来的偏移。即使三帧之间准确移动了 2π/3，共同起点仍可能未知。本页假设该偏移在三帧内保持不变。

波矢 k：条纹的实际方向和间距由样品处两束光的传播方向决定。光束夹角或对准的偏差会改变波矢；换算成图像中的频率格，还需要准确的样品面像素尺度。

从样品 Sample 到样品频谱 Spectrum

s(r) = s(x, y) 表示像素位置 r = (x, y) 处的样品强度。二维离散傅里叶变换（Discrete Fourier Transform，DFT）把这些像素展开到不同频率的基函数上；S(q) = S(qₓ, qᵧ) 是频率 q 对应的复数系数，包含幅度和相位。FFT（Fast Fourier Transform）是计算 DFT 的快速算法。

本页 N = 128，x、y 为 0—127 的像素索引；qₓ、qᵧ 是带符号的整数频率格。频谱以零频为中心显示，每移动一格，对应沿该坐标方向跨整个视野多振荡一个周期。正变换使用负指数且不归一化，与本页计算核心一致。

单个 q 对应复指数基函数。实值样品的 q 与 −q 两个系数共轭配对，合成一张实值余弦条纹：条纹垂直于 q，沿 x、y 的有符号周期数分别为 qₓ、qᵧ。该条纹的峰值幅度是 2|S(q)|/N²，相位 arg S(q) 决定平移位置。第 01 步的“频域里的点，怎样变成空域条纹？”可独立演示这一对应关系、复系数和逐像素加权叠加。

因此，选中的这个分量沿 x 方向跨整个视野有 14 个周期，沿 y 方向不变。这里解释的是该频率分量，完整样品由许多分量共同构成。右侧频谱图用 log(1 + 幅度) 显示亮度，内部计算保留完整复数。

R₀ 很小时，直接取倒数仍可能放大噪声，加入 w² 可以限制增益。若所有频带在某个频率处都无法传递，R₀ = 0，该频率的信息也无法凭归一化产生。对不同噪声方差的观测，可进一步使用相应的加权最小二乘；这里先展示等权基础式。

RMSE 从哪里来，用来评估什么？

RMSE 是 Root Mean Square Error，均方根误差。它是重建结束后计算的图像误差指标；不是要事先选择的重建参数，不参与解混、归位或 Wiener 滤波。把待评价图像与真值在同一位置相减，逐项平方、求平均、再开平方：

样品真值有 128 × 128 个像素，输出有 256 × 256 个像素，视野相同。因此输出的 (2x, 2y) 与真值的 (x, y) 对齐；128² 是参与比较的 16384 个像素数。宽场本来就是 128²，直接在 (x, y) 比较。RMSE 用全图计算，与下方仅显示 y = 80 一行的强度剖面不同。

平方防止正负误差相互抵消，也使大误差受到更强惩罚；开平方使结果与像素强度具有相同单位。比如只有两个像素，误差为 +0.1、−0.1，平均误差是 0，但 RMSE = 0.1。对同一真值、同一强度标尺和配准方式，RMSE 越小代表逐像素强度越接近，0 表示完全一致。

为什么本例 SIM 的 RMSE 反而较大？固定版本在分母额外累计 0 级，但分子没有同样增加；再加正则化和切趾，整体强度与频率幅度都会受到抑制。这会进入逐像素误差。本例低频和高频同时有变化，不能只凭“找到非零高频”断言全图强度更准确。

RMSE 综合反映亮度、对比度、噪声、错位等造成的像素误差；它没有单独给出“最小可分辨间距”。本演示将剖面、同一高频的恢复量与 RMSE 分开报告。无真值的真实实验不能直接计算这种对真值的 RMSE；无噪声宽场也不是等光子预算下的性能对照。显示图使用 0—1 标尺，但计算使用未截断数据，0.2643 不等于“分辨率误差 26.43%”。
