# Open-3DSIM 文献条目

## 文献

Cao, Ruijie et al. “Open-3DSIM: an open-source three-dimensional structured illumination microscopy reconstruction platform.” *Nature Methods* 20, 1183-1186 (2023). DOI: [10.1038/s41592-023-01958-0](https://doi.org/10.1038/s41592-023-01958-0).

## 文件说明

- `Open-3DSIM.pdf`：论文本地副本。
- `metadata.yaml`：题录、关键词、代码和数据来源。
- `citation.bib`：BibTeX 引用条目。
- `中文译文.md`：主文和 Methods 的中文工作译稿，保留重建流程、滤波思想、实验条件、图注和扩展数据概要。
- `理解笔记.md`：面向 3D-MP-SIM/SIM+深度学习课题的算法拆解、公式和工程对照。
- `中文译文预览.html`、`理解笔记预览.html`：使用项目 KaTeX 脚本生成的本地预览。

## 代码与数据

- Open-3DSIM 代码、测试数据和用户指南：<https://github.com/Cao-ruijie/Open3DSIM>，论文声明 Apache License。
- 补充数据、参数、比较结果和 ImageJ 安装视频：<https://figshare.com/articles/dataset/Open_3DSIM_DATA/21731315>。

译文是毕业课题阅读用工作稿，不替代原文及补充材料。论文重点是开放式 3D-SIM 重建平台和频谱优化，不是深度学习重建方法。
