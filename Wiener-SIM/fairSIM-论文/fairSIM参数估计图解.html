fairSIM 参数估计图解

配合 SimAlgorithm.estimateParameters 的粗定位阶段 · 五张图看懂"互相关找峰"

① 核心事实：边带就是中心频带的"平移副本"

频域视角 · C₊₁(q) ≈ (m/2)·e^{iφ}·S(q − k₀)

蓝盘是普通宽场频谱（band0），橙盘是分离出的边带 band+1。两者在重叠区装着完全相同的样品信息 S̃，只差一个整体平移 k₀ 和一个复常数 (m/2)e^{iφ}。"k₀ 是多少"就是我们要求的答案。

② 互相关 = 把边带滑回去，看重叠什么时候最大

c1.timesConj(c0) → IFFT · 互相关定理

代码 fft2d(c0,true); fft2d(c1,true); c1.timesConj(c0); fft2d(c1,false) 就是在做这件事：把 band1 相对 band0 逐步平移并计算重叠积分。当平移量恰好等于真实的 k₀ 时，两盘的样品频谱完全对齐、重叠最大，相关图在这里冒出一个峰——峰坐标就是 (kx,ky) 的粗估值。

③ 麻烦：DC 自相关在原点制造一个"假峰"

writeAttenuationVector(otfAtt, .99, 0.15·cutoff, 0, 0)

第一次分离用的是猜的相位，所以边带里泄漏了一部分 DC（图像平均亮度，能量比信号大几个数量级）。它和 band0 的 DC 相关，在原点堆出一个巨大的红色假峰，可能盖过绿色的真峰，让 locatePeak 锁死在原点。
解决办法：频谱乘上一个以 DC 为中心的高斯软凹陷（str=0.99 → DC 处只留 1%，宽度 0.15×截止频率）。真峰在 k₀ 处、远在凹陷之外，几乎不受影响。用软凹陷而非硬置零，是为了避免频域硬边界带来的振铃。

④ 再加一道保险：fitExclude 划出"禁区"，只在环带里找峰

minDist = fitExclude · cutoff / pxlSizeCyclesMicron; locatePeak(c1, minDist)

软凹陷只压得住紧贴 DC 的一小块。厚样品背景、照明不均等"准 DC"能量会在原点附近形成更广的隆起，尾巴可能伸出凹陷。fitExclude 补一句物理约束：能超分辨的结构光，条纹周期不可能太长，|k₀| 必在截止频率一半量级以上。于是把原点周围一整片灰色禁区排除，只在环带里找最高峰，杜绝低频隆起冒充条纹。
（注：fitExclude=0 时压根不找峰，直接用预设 k 矢量当起点。）

⑤ 一个复数峰 → 三个参数全出来

return { kx, ky, resPhase, resMag }

这就是整套方法优雅的地方：不需要分别去求三个量。相关峰是一个复数——它的坐标给出波矢 (kx,ky)，相位角给出条纹相位 φ，模长给出调制度 m。粗定位到整像素后，再交给 fitPeak 做三轮 10×10 网格的亚像素精修（每轮搜索半径缩小到 1/5）。
