重建图谱的 fairSIM 实现对照

本页记录 SIM 重建图谱 的具体计算约定。2026-09-30，图谱从自行设计的噪声加权模型改为固定 fairSIM 二维 Wiener 路径；模拟采集和交互实验继续由网页提供。

固定来源与配置

  • 论文：Müller et al., Nature Communications 7, 10980 (2016), DOI 10.1038/ncomms10980。
  • 源码：fairSIM，本地 develop 提交 711afd12cb8c4fd4207bbca7ee7610c5aed4f732，pom 版本 1.5.1。这是后续维护版本，不是 2016 年代码快照。
  • 分支：SimAlgorithm.runReconstruction 的二维 Wiener 分支，otfBeforeShift=false，CLIPSCALE.NONE。
  • OTF：OtfProvider.fromEstimate 的理想圆瞳，曲率参数 a=1；512 个 float 采样点及线性插值；与模拟采集使用同一 OTF。
  • OTF attenuation 关闭，RL 关闭；切趾选择 ISOTROPIC。
  • 默认参数：Wiener w=0.05，切趾截止倍数 1.9，指数 β=0.8，取自 StepByStep.java。其余示例参数没有被当作必须照搬的物理标定。
  • JavaScript 移植在 sim-atlas-core.js，原始 GPL 许可保留于 LICENSE。

数据流与公式

采用页面的负指数傅里叶约定及 y 随像素行向下的坐标。fairSIM 的 y 轴向上；数值对照入口显式翻转 setPxPy 的 y 符号。

  1. 由样品生成三方向、每方向三相位的采集帧。泊松计数、已知背景与读出噪声属于模拟采集；扣背景及单位转换后输入重建。
  2. 分离矩阵同时包含相位和调制度。设 a0=1a_0=1a0​=1，a±1=m/2a_{\pm1}=m/2a±1​=m/2，有

Dj=∑ℓ=−11aℓeiℓϕjAℓ,Aℓ(f)=H(f)S(f−ℓkd).D_j=\sum_{\ell=-1}^{1}a_\ell e^{i\ell\phi_j}A_\ell, \qquad A_\ell(\mathbf f)=H(\mathbf f)S(\mathbf f-\ell\mathbf k_d).Dj​=ℓ=−1∑1​aℓ​eiℓϕj​Aℓ​,Aℓ​(f)=H(f)S(f−ℓkd​).

等间隔三相位时，逆矩阵系数为 uℓ,j=e−iℓϕj/(3aℓ)u_{\ell,j}=e^{-i\ell\phi_j}/(3a_\ell)uℓ,j​=e−iℓϕj​/(3aℓ​)。OTF 保留在结果中，调制度已经补偿，不在后续分母重复乘入。

  1. 各频带从 128 × 128 填充到 256 × 256，然后归位。DFT 格距和视野不变，网格可表示的最高频率扩大。
  2. 在归位坐标乘共轭 OTF 并相加，得到 U=∑bHb∗CbU=\sum_b H_b^*C_bU=∑b​Hb∗​Cb​。没有另加频带噪声方差权重。
  3. 按原实现分母取倒数并相乘，得到切趾前频谱；再乘切趾窗并逆 FFT。

Fpre=UDcode+w2,Fout=AFpre.F_{\mathrm{pre}}=\frac{U}{D_{\mathrm{code}}+w^2},\qquad F_{\mathrm{out}}=A F_{\mathrm{pre}}.Fpre​=Dcode​+w2U​,Fout​=AFpre​.

保留原实现的零级计数

WienerFilter.addWienerDenominator 对正负移位各加一次，在 b=0 时两个移位都为零；分子对零级只加一次。本页如实保留这一行为：

Dcode=∑d(2∣Hd,0∣2+∣Hd,+1∣2+∣Hd,−1∣2).D_{\mathrm{code}}=\sum_d\left(2|H_{d,0}|^2+|H_{d,+1}|^2+|H_{d,-1}|^2\right).Dcode​=d∑​(2∣Hd,0​∣2+∣Hd,+1​∣2+∣Hd,−1​∣2).

因此，定义 Q=∑b∣Hb∣2Q=\sum_b|H_b|^2Q=∑b​∣Hb​∣2 后，理想匹配信号的传递为

Gpre=QDcode+w2,Gout=AQDcode+w2.G_{\mathrm{pre}}=\frac{Q}{D_{\mathrm{code}}+w^2},\qquad G_{\mathrm{out}}=A\frac{Q}{D_{\mathrm{code}}+w^2}.Gpre​=Dcode​+w2Q​,Gout​=ADcode​+w2Q​.

不能继续沿用旧页面的 G=W/(W+w2)G=W/(W+w^2)G=W/(W+w2)，也不能断言 w=0 时有信号的频率全部恢复到 1。本版本输出的直流和幅度会受到原计数的影响；没有额外按真值修正亮度。因此绝对强度 RMSE 不保证优于无噪声宽场。

输出标度

原始 Java 输出与网页的 outputNative 都是 256 网格的逆 FFT。因为输入 FFT 是 128 网格的未缩放和，而逆 FFT 按 256² 归一化，网页显示使用固定因子 4：

sdisplay=4Re⁡F256−1(Fout).s_{\mathrm{display}}=4\operatorname{Re}\mathcal F^{-1}_{256}(F_{\mathrm{out}}).sdisplay​=4ReF256−1​(Fout​).

这只转换采样网格带来的强度标度；没有依赖样品真值的缩放、直流校正或负值截断。RMSE 使用 s_display(2x,2y) 在原 128 网格位置与真值比较。重建图与剖面则保留完整 256 输出。

明确的适用边界

  • 波矢、相位及 OTF 由模拟标定提供。可选的 m 估计器仍是 sim-experiment.js 的教学模块，不是 fairSIM 参数估计器。
  • 按 SimParam.Dir.getModulations，m 超出 [0.4,1.1] 则采用 0.65；估计失败也触发此回退，不再用旧页面的弃带策略。
  • w=0 是额外的数学教学实验；分母为零处输出置零，避免原始算式 0/0。Java 对照采用 w>0。
  • 图谱只接受当前三相位采集。不可逆相位矩阵返回错误；没有将 fairSIM 的任意相位数伪逆、完整插件 GUI 或参数估计流程移植进来。
  • 阶段 08 的频谱显示取对数，Wiener 后和切趾后两张图使用共同标尺；切趾窗线性显示。复数频谱在计算中保持完整。

实际数值对照

运行：

node --test tests/sim-atlas-fairsim.test.cjs
node --test tests/sim-atlas.test.cjs tests/sim-page-boundary.test.cjs
node tests/sim-atlas-browser.test.cjs

第一项需要 JDK 11 或以上。测试直接编译本地原始 SimAlgorithm、BandSeparation、WienerFilter、OtfProvider 及所需线性代数类，没有改写这些 Java 重建代码。测试用的小型 radix-2 FFT 适配器仅替代外部 JTransforms 后端，避免依赖 ImageJ；它不包含重建逻辑。

相同采集帧输入 Java 和 JavaScript，逐像素比较完整 256 × 256 原生输出：无噪声三方向、低光子数、单方向、非整数搬移与相位/OTF 失配、m 回退、切趾参数变化。六组实测最大绝对误差约 4.1×10−84.1\times10^{-8}4.1×10−8（原生 FFT 标度），差别处于浮点精度量级。该结果验证上述配置的重建移植，不代表完整 ImageJ 插件已被复现。
