交互页面分工

两个计算页面职责不重叠，按“先实验、后俯瞰”使用；第三页是纯静态硬件示意，不参与计算。改任何一页前先确认它属于哪一类，不要把另一类的职责搬过来。

页面 解决什么问题 明确不负责 页面独占模块 验收
sim_interactive_demo.html 参数与误差实验台：四类共 11 项单变量 A/B 对照、调制度 mmm 的数据估计与可靠性筛查、相机噪声模型、CH1–CH4 截线波形、成像模型的二维卷积 ⇄ OTF 对照（PSF、截止与像差后果） 不逐个展示重建流水线的频谱中间产物，不做流水线全景俯瞰 sim-lab/：启动、成像、采集、预设、对照与样式 tests/sim-browser.test.cjs
sim_pipeline_atlas.html 按固定 fairSIM 二维 Wiener 路径展示中间产物，点开频谱核对相移解混与归位 不替代完整的单变量 A/B 实验台 sim-atlas-core.js、sim-atlas.js、sim-atlas.css tests/sim-atlas.test.cjs、tests/sim-atlas-fairsim.test.cjs（JDK）、tests/sim-atlas-browser.test.cjs
sim_real_optical_path.html 真实 2D-SIM 光路走查：17 个工位从 488 nm 激光到样品条纹，逐站交代光束状态（波前 / 束径 / 偏振）、为什么非有不可、装错会变成哪种伪影；含共轭面链、BFP 正视图、入射角真实比例图与关键量核算表，每条论断带证据标签（S 编号 / H / 量级 / 待核实） 不做任何数值计算与参数实验（纯静态 SVG，内联脚本只管着色切换、滚动联动与高亮；不依赖共享计算层，页面上每个数字都是预先核算后写死的） 无（内联脚本与样式） 离线打开即用；无远程依赖由 tests/sim-page-boundary.test.cjs 断言

共用计算层：sim-core.js（理想教学模型：OTF、前向成像、相移解混、Wiener 融合）与 sim-experiment.js（有效参数实验层：瞳面截光、可见度、相机噪声、mmm 估计）被两个页面共同依赖，改动会同时影响两页，提交前必须跑全部单测。页面独占模块不得被其他页面引用，共享层不得反向依赖页面，删除页面时必须一并清理其独占模块——这三条由 tests/sim-page-boundary.test.cjs 断言，不靠约定。

node --test tests/sim-core.test.cjs tests/sim-experiment.test.cjs tests/sim-atlas.test.cjs tests/sim-page-boundary.test.cjs tests/sim-preview.test.mjs
for f in tests/sim-browser.test.cjs tests/sim-atlas-browser.test.cjs; do node "$f"; done
