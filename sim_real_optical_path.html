CONJUGATE PLANES

整台机器只有两组共轭面，其余都是中继

看光路图最容易把元件顺序背下来却不知道为什么这么摆。真正的骨架是两组共轭关系：组 A（空间面）管「条纹在视场里均不均匀、相位怎么移动」，组 B（角谱面）管「条纹有多密、以什么角度入射」。两组的职责不能互换。

两组共轭各管一件事。组 A 成立 ⇒ 把 SLM 上的光栅横向平移 Λ/3，样品面的条纹就平移一个相位 2π/3，而且整个视场内两束光完全重叠（否则视场边缘对比度会塌下来）；组 B 成立 ⇒ 掩模上两个孔的间距直接等于 BFP 上两个焦点的间距，也就是直接等于照明角度与条纹周期。

为什么条纹周期与波长无关（一个常被误传的结论）

光栅方程给出 sinθ₁ = λ/ΛSLM；L1 把它变成位置 x = f₁·sinθ₁；L2–L3 把掩模面成像到 BFP，半径 r = (f₃/f₂)·x；物镜的正弦条件给出 r = f_obj·NA_ex。串起来：

NA_ex = (f₃·f₁·λ) / (f_obj·f₂·Λ_SLM)
Λ_样品 = λ / (2·NA_ex) = (f_obj·f₂·Λ_SLM) / (2·f₃·f₁)

λ 在第二式里约掉了：同一张光栅图案在 488 / 560 / 640 nm 下给出几乎相同的条纹周期（前提是光学系统满足正弦条件、且未因波长变化而重新对准）。这就是多色 SIM 能共用一套图案几何的原因。H

把两组共轭搞反会怎样

  • 若把 SLM 面成像到 BFP（组 A/B 互换）：SLM 的像素结构会变成角度结构，照明不再是干净的平面波对，条纹对比度直接崩塌。
  • 若掩模面不在 L1 焦面（偏离频谱面）：孔就不再对应单一角度，而是一个角度范围，等效于照明 NA 展宽 → 条纹周期不再单一、重建时波矢失配。
  • 若掩模两孔不对称（偏心或孔径不等）：I₁ ≠ I₂，调制度从 m=v 降到 m=2v√(I₁I₂)/(I₁+I₂)，且有效载频也跟着偏移——这正是模拟台第 6 组（光路近似）在模拟的事。

STATION WALKTHROUGH

17 个工位：逐站走查

每站三栏固定：做什么（事实）、为什么非有不可（删了会少什么物理）、装错会变成什么（对应哪种重建伪影）。第三栏是光路页最有用也最少被写的部分：SIM 的重建伪影绝大多数可以回溯到光路上的某一个具体错位。

GROUP A

光源与稳束

目标：把“一束激光”变成“方向、偏振、模场、时机都确定的光”

01

488 nm 激光器 相干光源 S3S8S10

S10 用的是 488 nm Genesis MX488-1000 STM；S8 的 Multi-SIM 组合 405 / 488 / 560 / 640 nm；S3 的自建系统同样是 488 nm 激光配 NA 1.49 TIRF 油浸物镜。本页以 488 nm 单色为例。

做什么

输出单频、线偏振、高亮度的 488 nm 相干光。它是整条链上唯一的光子来源，也是唯一决定波长 λ 的元件——后面所有透镜、掩模、二向色镜都只是搬运和筛选它。

为什么非有不可

SIM 的物理基础是两束光在样品面干涉，而干涉需要三个条件同时成立：时间相干（单频，相干长度远大于两束光的光程差）、空间相干（干净的单模波前）、偏振可控（线偏振才能用波片精确旋到 s 方向）。宽场灯源三条都不满足，所以 SIM 必须用激光。

装错会变成什么

多模或波长漂移 → 相干长度下降 → 两束光光程差一旦超过相干长度，干涉项直接消失（v→0），重建退化为宽场却带着 SIM 的噪声放大。功率不稳 → 9 帧之间亮度不一致 → 相移矩阵条件数变差，解混出现频带串涂。

λ = 488 nm线偏振，方向固定相干长度 ≫ 系统内两束光程差单横模
本页未引用的量与假设

到样品面的绝对功率与强度（kW/cm² 量级）在本地四篇文献的方法段中均未给出，因此本页不写具体功率数字。S10 仅给出激光器型号，型号后缀通常表示输出功率等级，但不得当作到样功率使用。待核实

“相干长度远大于光程差”是干涉成立的必要条件，属于基础光学结论；具体到 SIM，两束光经 SLM 衍射后光程差由掩模两孔到样品的路径差决定，量级为毫米到厘米。H

02

AOTF 声光可调滤波器 波长选择 + 曝光光门 S5S8S10

射频（RF）驱动在声光晶体里建立行声波栅，只有满足布拉格条件的那一个波长被高效衍射出去。三篇文献都把它描述为“切换波长、调节功率和照明时长”的元件。

做什么

三件事合一：① 从多色激光里选出 488 nm；② 用 RF 幅度连续调功率；③ 用 RF 开关做微秒级光门，决定“这一帧曝光期间到底给不给光”。

为什么非有不可

2D-SIM 一个视场要 9 帧，3D-SIM 要 15 帧以上，活细胞成像每帧只能给几十毫秒。机械快门和滤光轮跟不上这个节奏，也无法做到“功率随帧可调”。更关键的是同步：S10 的触发链里，是相机全行曝光完成后的 global exposure 输出去触发 AOTF 开门，因此激光只在真正积分的区间内到达样品——这直接决定了光毒性预算。

装错会变成什么

AOTF 的衍射角随 RF 频率变，所以调功率或换波长时出射指向会漂。如果不把指向漂洗掉（下一站的光纤就是干这个的），照明角度就会跟着漂 ⇒ 条纹周期与相位帧帧不同 ⇒ 重建出现方向性伪影与频谱接缝。RF 幅度未逐波长标定 → 各帧强度不一致 → 解混矩阵失配。

切换时间量级 µs衍射效率随 λ 与 RF 幅度变指向随 RF 频率微变
S10 记录的真实触发链

SLM 的 LED_EN TTL 作主触发 → 启动两台工作在 global reset 模式的 sCMOS → 相机全行曝光后由 global exposure 输出触发 AOTF 打开激光 → SLM TTL 检测到 5 个下降沿后调整 HS-LCVR 电压，15 个下降沿后移动轴向相移压电台（后两项属于 3D-SIM/MP-SIM，本页的 2D-SIM 光路不涉及）。S10

注意这里的因果方向：不是“激光先开、相机后曝光”，而是相机反过来门控激光。这保证了曝光区间内光强恒定，也把漂白限制在真正有用的时段。

03

耦合镜 + 保偏单模光纤 空间滤波 · 指向稳定 · 偏振锁定 S10

S10：“经 AOTF 耦合到保偏单模光纤。出纤光经准直后进入偏振分束器…”。这是整条链上最不起眼但最关键的一站：它把前面所有不稳定因素一次性洗掉。

做什么

耦合镜把 AOTF 出射光会聚到单模纤芯（µm 量级）上，光在光纤里以单一横向模传输，出纤时变成一个发散锥。保偏纤额外把线偏振锁定在自己的慢轴上。

为什么非有不可

三个作用同时成立：① 空间滤波——单模光纤只支持一个横向模，高阶模、AOTF 零级、杂散光全部被挡，出纤是干净的近高斯波前；② 指向稳定——纤芯位置是固定的，AOTF 的指向漂移和激光器热漂全部被吸收，下游光路不再动；③ 偏振锁定——出纤偏振方向确定，这是第 11 站能精确把光转到 s 偏振的前提。

装错会变成什么

耦合偏心 → 激发高阶模或保偏失效（偏振串到快轴）→ 出纤偏振不纯 → 干涉可见度 v 下降。纤芯不在准直镜焦点上 → 出射不是准直而带残余发散/会聚 → SLM 上各处入射角不一致 ⇒ 视场内条纹周期不均匀。弯折半径过小或受应力 → 双折射随时间漂 → 调制度慢漂。

纤芯 µm 量级单横模保偏轴锁定线偏振
哪些是文献、哪些是推导

“AOTF 之后耦合到保偏单模光纤，出纤后准直”是 S10 的原话。S10；光纤型号、长度、NA 与弯折半径本地文献未给。待核实

“空间滤波 / 指向稳定 / 偏振锁定”三个作用是从单模与保偏光纤的物理定义直接得出的，不是 S10 的原话。H

04

光纤准直镜（含扩束） 发散锥 → 准直平面波 S8S10

S10：“出纤光经准直后…”；S8：“…再经 4f 系统扩束”。无焦倍束系统的两个职责（准直 + 把束径放大到下游元件口径）在这一站完成。

做什么

把纤芯放在透镜前焦点上，出射就是准直平面波；束径 D ≈ 2·f·NA_fiber。若需要更大束径，再接一组无焦望远镜（f₂/f₁ 定倍率）。

为什么非有不可

SLM 要求入射是准直平面波：否则 SLM 不同位置看到的入射角不同，同一张光栅图案产生的衍射角就会随位置变化，等效于条纹周期在视场内不均匀。同理，后面所有偏振元件（波片、PBS、LCVR）都是按正入射设计的，斜入射会引入额外延迟。

装错会变成什么

束径不够覆盖 SLM 有效区 → 只有一部分区域被调制 → 视场照明不均、边缘调制度下降。准直不准（纤芯偏离焦点）→ 残余发散使束径随传播距离变 → L1 焦面上三个焦点的位置与大小都错 → 掩模孔径对不准。

束径 3–8 mm（量级）波前：平面需覆盖 SLM 有效区
为什么把扩束归到这一站

准直与扩束在光学上都是无焦倍束系统，差别只在焦距比。S8 把它们写成两步（“经 AOTF…再经 4f 系统扩束。半波片、偏振分束器和 SLM 共同调制光束”），S10 只写“准直”。本页合并为一站，以免把同一个功能拆成两个不存在的元件。具体焦距与倍率本地文献未给。待核实

GROUP B

偏振与结构光生成

目标：把偏振调到 SLM 能调制的方向，再用一张相位光栅把一束光变成一组角谱

05

PBS 偏振分束器 定义偏振纯度 · 兼作进出分离 S5S8S10

三篇文献都把偏振分束器列为照明图案生成链的一环（S5：“照明图案由偏振分束器、消色差半波片和铁电空间光调制器生成”）。

做什么

按偏振把入射光分成两支（典型地：p 透射、s 反射），只取其中一支往下游送。同时，因为 SLM 是反射式，它还兼任进出分离：入射光透过去 SLM，返回光偏振态改变后被折转 90° 送出照明模块。

为什么非有不可

消光比直接决定干涉可见度。干涉项带一个偏振重叠因子 |e₁*·e₂|；如果入射偏振里混了正交分量，那部分光不参与干涉，只会抬高非调制背景 I_u，把 m 拉下来。激光器自带的偏振纯度通常不够，需要一个高消光比的 PBS 重新定义。

装错会变成什么

PBS 轴与后续波片轴对不齐 → 实际偏振方向偏离设计值 → 第 11 站转出来的不是真 s 偏振 → m 下降且随方向不一致。若不用 PBS 而靠 SLM 轻微倾角做进出分离，则返回光会带上空间不均匀的相位，影响条纹平坦度。

本地文献没有写清的部分

S5/S8/S10 都只写了“偏振分束器 + 半波片 + 铁电 SLM”，未说明是否另有四分之一波片、也未说明进出分离具体怎么做。反射式 SLM 必须解决进出分离，常见两种方案：① PBS + 波片（进出成 90°，本页采用）；② SLM 相对光轴轻微倾角，入射与反射差两倍倾角。两者对后续光路的影响不同，需按实机确认。待核实

“铁电液晶 SLM 是反射式（LCOS）”是这类器件的通行构造（液晶层做在带反射镜的硬基背板上），不是本地文献的原话。器件常识

06

消色差半波片 把偏振转到 SLM 的调制轴 S5S8S10

S5 写的是“消色差半波片”，S8 与 S10 写“半波片”。两者都是同一个功能：旋转线偏振方向，转角等于波片快轴与入射偏振夹角的 2 倍。

做什么

把第 05 站定义好的线偏振旋到与 SLM 液晶指向矢平行的方向，使 SLM 能施加完整的相位调制。

为什么非有不可

液晶器件只对沿液晶指向矢的偏振分量产生相位延迟。入射偏振不平行于该轴时，只有投影分量被调制，剩下那一支要么被 SLM 自带的偏振片吸收（损失功率），要么以未调制的 0 级形式存在（直接拉低调制度）。

为什么必须“消色差”：普通单级半波片的 π 延迟只在设计波长成立。S5/S8 的机器同时有 488 / 560 / 640 nm，只有消色差波片能在整个波段近似给出 π，否则换波长后偏振方向就会偏。

装错会变成什么

角度读数误差会被放大两倍（转角 = 2θ）：波片差 5°，偏振就差 10°。多色系统用非消色差波片 → 不同波长的调制度不一致 → 多色图像的 m 不同，双通道定量对比失真。

半波片与 LCVR 的分工

两者都能旋转线偏振，但职责不同：半波片是一次性静态对准（把偏振对到 SLM 调制轴）；第 11 站的 HS-LCVR 是逐帧快速旋转（把偏振对到每个照明方向各自的 s 方向）。S10 明确用 LCVR 做快速旋转，而不是转半波片。S10

反射式铁电 SLM：相位光栅 结构光的角谱在这里产生 S3S8S10

S8 写明型号为 QXGA-3DM；S3 写“通过铁电液晶空间光调制器生成不同周期的照明图案”；S10 的 SI 还提到纯相位 HS-SLM 快速相移光路。铁电液晶是双稳态二值（0 / π）相位器件，切换在亚毫秒量级。

做什么

在屏上写一张光栅相位图案，把一束准直光衍射成 0、±1、±3… 一组离散角度。整份 9 帧数据完全由屏上的 9 张图案产生：转光栅方向 → 换照明方向 θ；换光栅周期 → 换条纹密度（即换 NA_ex）；把光栅横向平移 1/3 周期 → 换相位 φ。全程没有机械运动部件参与照明编码。

为什么非有不可

它是整条链上唯一能按帧重编程的元件。固定光栅只能给一个方向、一个周期；转轮式光栅有机械惯性。铁电液晶的亚毫秒切换使 9 帧能在百毫秒量级内完成，S10 甚至把 SLM 的 LED_EN TTL 用作整机主触发——也就是说 SLM 不只是元件，它是采集时序的主钟。

装错会变成什么

相位深度偏离 π（波长不匹配、温度变化）→ 0 级重现 → 三束干涉 → 你以为在做 2D-SIM，实际混进了轴向调制。像素填充因子低、像素间死区宽 → 有效相位深度下降 + 高次衍射增强。SLM 面不在共轭组 A 上 → 视场内条纹对比度不均。

±3 级的角度是 ±1 的三倍，对应 NA = 3·NA_ex，远超物镜 NA，绝大多数情况会被孔径切掉。但切掉的位置不受控，会变成杂散光与耀光；若光栅较粗（NA_ex 较小）而 ±3 仍在孔径内，它会在样品面形成周期为 Λ/3 的寄生条纹，在频谱上多出重建模型（只假设 0、±1）无法解释的频带 ⇒ 鬼影与条纹伪影。这就是第 09 站掩模存在的第二个理由。H

目标：把“一堆角度”筛成“正好两个角度”，再把它们准确投到 BFP 上

08

L1 傅里叶透镜 角度 → 位置 S10

S10：“自定义掩膜位于 L1 焦平面”。这一站的存在理由只有一句话：掩模是实物，只能挡位置，不能挡角度。

做什么

对 SLM 出射的每一个衍射级做一次傅里叶变换：一束与光轴成 θₙ 的准直光，会聚到后焦面上距轴 xₙ = f₁·sinθₙ ≈ f₁·nλ/Λ_SLM 的一个点。五个级次就变成五个分得很开的亮点。

为什么非有不可

要把“不要的角度”去掉，必须先把角度信息变成可以用一层金属膜挡住的东西。这就是频谱面的意义：它把角谱展开成空间分布。同时，L1 与 L2 组成 4f 中继的前半段，使掩模面能被成像到 BFP（共轭组 B）。

装错会变成什么

掩模不在 L1 后焦面 → 每个“点”变成弥散斑，孔的边界不再对应单一角度 → 通过的是一个角度范围而不是一个角度 ⇒ 等效于照明 NA 展宽、条纹周期不再单一，重建时波矢失配、频谱接缝。

09

掩模：±1 级光阑 2D-SIM 与 3D-SIM 的分水岭 S5S8S10

S5：“空间掩模滤除除 ±1 级之外的高衍射级次”（这是 2D / GI / TIRF-SIM）。S10：“自定义掩膜位于 L1 焦平面，仅允许 0 和 ±1 级通过”（这是 3D-SIM）。两者差的那一个孔，就是两种成像模式的全部区别。

做什么

L1 后焦面上的一块不透明板，在 ±1 焦点处开孔放行，在 0 级与 ±3 级以上位置保持不透明。

为什么非有不可

只通 ±1 ⇒ 只有两束光。两束光的极角完全相同（都是 α），因此它们的波矢差 p_z = 0，干涉条纹是纯横向的——沿 z 方向条纹完全不变。这正是 2D-SIM 的定义性特征，也是它没有光学切片能力的根本原因。一旦 0 级也通过，就变成三束干涉（0 级沿轴、±1 斜入射），轴向波矢差不为零，条纹沿 z 有明暗层——那就是 3D-SIM。

装错会变成什么

① 0 级漏过：采集仍按 2D-SIM 的 3 相位做，但数据里混了三束干涉 ⇒ 方程组不闭合 ⇒ 蜂窝与条纹伪影；② 孔太大：一个角度范围通过 ⇒ 条纹周期不单一；③ 孔太小：截掉光束边缘 ⇒ 光子数下降、有效载频偏移；④ 两孔不对称：I₁≠I₂ ⇒ m = 2v√(I₁I₂)/(I₁+I₂) < v。

孔间距 2f₁λ/Λ_SLM挡：0、±3、±5…通：仅 ±1
一块固定掩模怎么服务三个方向？

三个照明方向的 ±1 焦点分别位于过中心的三条不同直线上（相隔 60°）。本地文献只写了“自定义掩膜”与“空间掩模”，没有给出孔的排布。常见做法有三种：① 在同一半径上按 60° 间隔开 6 个孔——因为一次只显示一张光栅，同一时刻只有一对孔受光；② 环形狭缝；③ 可旋转掩模。待核实

L2 + L3 中继（含 M1 转向镜） 位置 → 角度 → BFP 实焦点 S5

S5：“激发光经中继系统耦合到物镜后焦面”。L2 与掩模面相距 f₂，把两个小孔的发散光重新变成两束准直但带 ±θ₂ 的光；机身照明端口内的 L3 再把它们聚焦到 BFP 上。

做什么

把掩模面成像到 BFP（共轭组 B，倍率 f₃/f₂）。L2 干“位置→角度”，L3 干“角度→BFP 上的位置”。

为什么非有不可

物镜只认 BFP 上的位置：正弦条件把 BFP 半径一一映射到样品空间入射角，r = f_obj·NA_ex。所以照明角度必须在 BFP 上“落点”。一束轴平行的准直光只会聚焦到轴上一点，不可能自己跑到离轴位置——这就是上一版光路图的几何硬伤，也是为什么必须有会聚锥而不是一根平行线。

装错会变成什么

掩模不在 L2 前焦面 → 出射不是准直 → BFP 上不是两个点而是两个弥散斑 → 照明角度展宽 → 条纹周期有一个分布，重建时无法用单一波矢描述。L2–L3 间距偏离 f₂+f₃ → 倍率错 → 实际 NA_ex 与设计值不符，条纹比预期粗（分辨率增益缩水）或细（超出物镜 NA 被切掉）。

HS-LCVR + 四分之一波片 把偏振转成 s：直接决定调制度上限 S10

S10：“HS-LCVR 与四分之一波片把线偏振旋转到垂直入射面，以提高结构光调制对比度”，并明确说“三束光被转换为垂直于入射面的 s 偏振”，且要“在亚毫秒照明下保持较高调制对比度”。

做什么

液晶可变延迟器（LCVR）+ λ/4 波片组成一个可调角度的偏振旋转器：延迟量 δ 随电压变，出射线偏振的旋转角随之变。逐帧把偏振转到当前照明方向对应的 s 方向。

为什么非有不可

两束光各偏轴 α，它们的偏振矢量夹角取决于偏振类型：s 偏振时两束 E 完全平行（都垂直于共同的入射面），重叠因子 |e₁*·e₂| = 1；p 偏振时要乘 cos2α。而高 NA 照明的 α 很大，cos2α 不仅小于 1，还会变负（相当于条纹多一个 π 相位）。更麻烦的是：三个照明方向的入射面各不相同，s 方向也跟着转，所以必须逐帧快速切换，这就是“HS”的含义。

装错会变成什么

不做偏振转换时，NA_ex = 1.26 的 p 偏振照明只剩 |cos2α| = 0.378 的对比度。因为边带信噪比按 m² 恶化，m 降到 0.378 意味着边带 SNR 只剩 14%；而且三个方向的 α 相同但入射面不同，若偏振固定不动，三个方向的 m 会各不相同 ⇒ 逐方向权重失配。

v_pol = 1（s）v_pol = |cos2α|（p）需逐方向切换亚毫秒响应
v = 1 是上限，不是实测值

偏振因子 1 只是理想上限。真实可见度 v = |γ₁₂|·|e₁*·e₂| 还受时间/空间相干度、随角像差、两束功率不平衡、SLM 衍射效率与边缘透过率限制，必须逐台标定。知识库对模拟台的“可见度边缘衰减 v(u)”也明确写了“曲线形状可推导，绝对幅度不可信”。H

二向色镜（45°） 光轴折转 90° · 激发/发射分离 S10

S10：“光束经自定义二向色镜反射到物镜后焦面，在样品处形成三束干涉结构光”（本页的 2D-SIM 是其中两束）。“自定义”这个词很关键：多色系统需要一块同时处理 488 / 560 / 640 nm 反射与多个发射带透射的多带分光镜。

做什么

45° 放置的长通（或多带）分光镜：对 488 nm 高反射，把水平入射的会聚锥折转 90° 送入物镜；对发射波段高透射，让荧光继续前行到探测臂。

为什么非有不可

落射荧光（epi-fluorescence）配置下，激发与发射共用同一个物镜，必须有一个元件按波长把它们分到两条路。高 NA 物镜只能从一侧接近样品（尤其是油浸、大角度照明），透射式照明无法达到 NA > 1，因此 SIM 必然采用落射式。

13

物镜后焦面 BFP 照明角度的硬件编码面 H

BFP 不是一个元件，而是物镜内部的一个平面——但它是整台 SIM 里最值得盯住看的位置：照明的一切信息都住在这个圆里。

做什么

±1 两级光在这里形成两个实焦点，位于光轴两侧 ±r。根据正弦条件，r = f_obj·n·sinα = f_obj·NA_ex，所以“两点离轴多远”直接等于“照明以多大角度打到样品”。

为什么非有不可

因为物镜只能把BFP 上的点变成样品空间的平面波（反之亦然）。这是傅里叶光学在硬件上的实现：BFP 是角谱面，样品面是空间面，两者互为傅里叶对。没有这个对应关系，“用光栅周期控制条纹密度”就无法实现。

装错会变成什么

两点不对称（一个离轴远、一个近）⇒ 条纹方向偏、且 I₁≠I₂ 拉低 m；两点太靠外超出后孔径 ⇒ 实际 NA_ex 低于设计值，条纹比预期粗，分辨率增益缩水；两点不是点而是斑 ⇒ 照明角度展宽，波矢不单一。这三个故障在重建里都表现为“估计出的波矢与真实不符”，因此它们也是参数估计失败的硬件根源。

高 NA 油浸物镜 BFP 半径 → ±α 平面波；兼做荧光收集 S3S8S10

S8：CFI SR HP Apochromat TIRF 100XC Oil，NA 1.49；S3：NA = 1.49 的 TIRF 油浸物镜；S10：60×/1.42 NA 油镜与 60×/1.27 NA 水镜（水镜用于水相厚样品以减小球差）。

做什么

双重角色。激发方向：把 BFP 上两个实焦点变成样品空间两束以 ±α 入射的平面波，sinα = NA_ex/n。发射方向：收集荧光并成像到相机面。

为什么非有不可

SIM 的总扩展带宽是两项之和：检测截止 2NA/λ_em + 照明载频 2NA_ex/λ_ex。两项都靠 NA。NA 不够，条纹就粗（载频小）、检测带宽也窄，两边同时缩水。要得到 Λ ≈ 172 nm 的条纹，必须 NA_ex ≥ 1.4，而 NA > 1 只能用浸没式物镜（空气极限 NA = 1）。

装错会变成什么

浸油折射率与盖玻片厚度不匹配 ⇒ 球差，而且大角度光线受影响最严重 ⇒ 恰好是承担照明的那两束边缘光先坏 ⇒ 条纹对比度随成像深度迅速下降（S10 改用水镜就是为了减小这一项）。盖玻片不是 0.17 mm 或校正领未调 ⇒ 实际 NA 达不到标称值。

样品面：±α 双束干涉 光路的终点，重建的起点 S8H

走了十五站，目的只有这一个：在样品上写下 I(r) = I₀[1 + m·cos(2πk·r + φ)]。荧光分子按这个强度分布被激发，于是样品频谱被搬到了相机能看见的地方。

做什么

两束相干平面波在样品面叠加，产生正弦强度分布；荧光分子按这个分布被激发，等效于用照明条纹对样品做频率编码（乘法）。

为什么非有不可

因为只有乘法才能产生 S(k±k_i) 两个搬移副本。把高频信息搬进 OTF 支撑域靠的就是这一乘；后面的重建只是把已知载频的副本搬回去。

装错会变成什么

两束不完全重叠 ⇒ 交叠区外只有单束照明，成为非调制背景 I_u ⇒ m 下降（但 Ī·m 不变，所以画面变亮不等于调制信息变多）；样品漂移或漂白 ⇒ φ 逐帧漂 ⇒ 频带串涂；条纹周期漂（温度/机械）⇒ 波矢失配 ⇒ 重建出现方向性重影。S8 专门指出条纹间距、角度与初相位会随机械、环境和温度漂移。

2D-SIM 的“平面”到底平在哪：它没有光学切片

只有照明是平面的（p_z = 0，条纹沿 z 不变）；探测仍然是 3D 积分：相机把焦面上下的荧光全部累加到同一帧里。因此 2D-SIM 没有光学切片能力，宽场 OTF 的 missing cone 并未被填充，它只提升横向分辨率。

这一点直接影响本页的读法：上面那张图里的条纹在 z 方向是一直延伸的，不像共聚焦那样只照一层。厚样品里离焦层同样被结构光激发，它们的荧光带着各自的条纹相位叠加到同一帧上，这正是 2D-SIM 在厚样品里背景偏高的原因。H

回程与采集

目标：把 10⁻⁶ 量级的漏激发光压下去，并把扩展后的带宽采样下来

16

荧光回程 → sCMOS 非本页重点，但是同一个物镜的回程 S10

S10 明确记录了这一段：“荧光经显微镜内部管镜后由 field stop 控制视野，随后经 4f 系统…投射到两台 Hamamatsu Flash 4.0 V3 sCMOS 相机”。本页把它压缩为一站，因为用户的需求边界是“从激光到样品”。

做什么

荧光被同一物镜收集 → 向下穿过二向色镜（长通，透射）→ 发射滤光片 → 内部筒镜 → field stop 限定视场 → 4f 中继 → sCMOS。

为什么非有不可

① 二向色镜 + 发射滤光片两道防线才能把漏激发光压到荧光之下（荧光比激发光弱很多个量级）；② field stop 挡掉视场外同样被结构光照亮、却不在成像范围内的荧光，否则它会在镜组内散射成背景；③ 4f 中继的倍率决定了样品面等效像素尺寸，而 SIM 把带宽扩了一倍，采样必须跟上。

装错会变成什么

发射滤光片 OD 不足 → 残余 488 nm 直进相机 → 背景抬高、m 的估计偏低。等效像素太大 → 奈奎斯特跟不上扩展后的截止频率 → 高频折叠成伪低频（混叠），在重建图上表现为摩尔纹与假细节。这是 SIM 特有的陷阱：普通宽场采样够了，换到 SIM 就不一定够。

17

3 方向 × 3 相位 = 9 帧 采集序列与它的两个“为什么是 3” S8S3

S8：“TIRF/GI-SIM 使用 3 个方向、每方向 3 个相位，共 9 帧；3D-SIM 使用 3 个方向、每方向 5 个相位、每个轴向切片 15 帧”。本页的 2D-SIM 对应前者。

为什么相位是 3 个

每一个检测频率 k 上混着 3 个未知量：S(k)H(k)、S(k−k_i)H(k)、S(k+k_i)H(k)。要解出 3 个未知量至少需要 3 个独立方程，而每一帧提供一个 ⇒ 至少 3 个相位。相位必须真正不同：重复的相位（包括相差 2π）不提供独立方程，矩阵不满秩。

为什么方向是 3 个

照明波矢 k_i 是有方向的，一次照明只把频谱沿一个方向搬移。要各向同性地扩展二维带宽，至少需要 3 个相隔 60° 的方向去覆盖平面；用 2 个方向会留下未扩展的角度扇区，重建图会出现方向性分辨率差异。H

采集不理想的后果

相位不等间隔 → 相移矩阵条件数变差 → 频带泄漏（条纹、重影、方向性伪影）。某个方向的 m 太低而被估计器拒用 → 该方向只用 0 级 → 重建在那个方向退化为宽场，表现为各向异性分辨率。这也是为什么模拟台把“估计器拒用一级频带”与“参数错误”当成两件事分开做 A/B。

WHAT THIS PAGE DOES NOT MODEL

本页的边界：哪些东西被当成理想了

一张光路图的危险在于：它看上去已经把系统说完了。下面这些本页完全没建模的因素，在真实系统里往往比元件顺序更决定最终图像质量。

波前与像差

  • 球差、彗差、像散等全部当零；特别是样品诱导像差（浸油/盖玻片/样品三层折射率失配），S6 指出它通常占主导地位，且随深度迅速恶化。
  • 大角度光线受影响最重，而承担照明的恰好就是这两束大角度光——所以像差对 SIM 的打击比对宽场更重。

SLM 器件细节

  • 像素填充因子、像素间死区、边缘电场均未建模；它们使有效相位深度偏离 π，从而让 0 级重现。
  • 二值相位深度随波长与温度变；本页 40.5% / 4.5% 的效率是理想方波结果，不得当标定值引用。
  • 铁电液晶的双稳态切换与灰度相位调制不同，本页未展开其驱动时序。

偏振与膜层

  • 二向色镜与各镜膜对 s/p 的反射率、相位差未建模；它们会在第 11 站之后再次降低有效 v。
  • LCVR 在大角度入射下的延迟量偏离标称值。
  • 本页把 v = 1 当作上限而不是期望值。

光场与样品

  • 不做完整衍射传播：有限光斑的包络、谱展宽、空间变化的调制度均未计算（模拟台也只用面积积分近似）。
  • 光漂白、样品漂移、活细胞运动未建模；而 S8 明确指出条纹间距、角度与初相位会随机械、环境和温度漂移。
  • 部分相干照明（|γ₁₂| < 1）未建模。

探测端

  • sCMOS 的像素间增益差异、饱和、量化、读出噪声分布均未建模（那是模拟台第三章的职责）。
  • 滤光片的真实光谱、多色串扰、相机 QE 随波长变化未建模。

3D-SIM 才有的元件，本页不画

  • 轴向相移模块（S10）：直角棱镜 + 回射空心屋脊棱镜 + P66.X60 压电台，位于 SLM 共轭平面附近；全行程 55 µm、稳定时间约 5 ms。它用于改变轴向结构光相位。
  • ISP 多平面分光与双相机（S10）：把荧光分成 8 个轴向区域投到两台 sCMOS。
  • 0 级通过的掩模配置：本页挡掉它，所以没有三束干涉与轴向调制。
  • 如果需要这些，应该另做一个 3D-SIM / MP-SIM 光路页，而不是在本页加开关。
