添加内容的顺序

  1. 新文献先登记文献目录，保存 DOI、原文与来源；未阅读条目不能直接写成结论。
  2. 论文译文和详细笔记放回对应论文目录；共通知识提炼进专题。
  3. 理论说明写清假设、符号和推导依据；使用 $...$ 与 $$...$$ 编写 LaTeX。
  4. 工程建议和待验证假设明确标注；复现实验完成后附数据、参数、版本与评价记录。
  5. 新章节使用稳定的显式锚点，并更新本页目录和知识库入口。
  6. 修改 Markdown 后重建预览；不要手工改生成的 HTML。

预览命令

在项目根目录执行：

node build_sim_preview.mjs --all
node watch_sim_preview.mjs

第一条生成资料库首页、知识库目录、8 个专题、维护说明、项目总览、文献目录、模拟台核对说明，以及 9 个文献目录中的条目说明、译文和笔记，当前共 37 页。监听模式覆盖这些 Markdown 文件的修改和专题/论文目录中的 Markdown 新增、删除；删除源文件后，旧预览可能仍在磁盘，但不再列入构建导航。

新增独立论文目录时，先更新文献目录，再将目录加入 build_sim_preview.mjs 的 paperDirs；已有目录中的新 Markdown 自动发现。重新启动监听以载入目录配置变更。

单独生成任意文档仍支持：

node build_sim_preview.mjs --source "HiFI-SIM/High-fidelity structured illumination microscopy by point-spread-function engineering-译文.md" --output "HiFI-SIM/HiFi-SIM译文预览.html"

预览在构建时使用本地 KaTeX 渲染公式；公式语法有误会报出源文件并停止写入。页面离线可读，无需联网加载公式或字体。marked 优先使用项目依赖，未安装时使用现有本机运行时，也可用 SIM_MARKED_PATH 指定模块文件。

批量构建管理的 Markdown 链接在预览中自动转为 HTML；代码、PDF 等仍指向原文件。图片和本地资源按输出目录换算相对路径，代码示例中的 $ 保留原样。只使用 --source 时默认生成同目录阅读页；--output 可指定输出位置。

构建后可运行：

node --test tests/sim-preview.test.mjs

这会检查生成页面的本地文件和锚点链接、公式渲染、代码示例中的数学定界符，以及不同输出目录中的相对路径。
