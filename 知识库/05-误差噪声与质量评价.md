## 1. 误差、噪声和伪影

<a id="s1-1"></a>

### 1.1. 噪声模型

荧光 SIM 至少要考虑：

1. 光子散粒噪声：近似 Poisson，$y\sim\mathrm{Poisson}(\mu)$；
2. 相机读出噪声：近似 Gaussian；
3. sCMOS 像素相关增益、偏置和方差差异；
4. 背景荧光、离焦光和自发荧光；
5. 光漂白造成的帧间强度衰减。

一个混合模型可写为

$$
 y_p=g_p\,\mathrm{Poisson}(\mu_p)+\epsilon_p,
 \qquad \epsilon_p\sim\mathcal N(b_p,\sigma_p^2),
$$

其中像素增益 $g_p$、偏置 $b_p$ 和方差 $\sigma_p^2$ 可能随像素变化。

<a id="s1-2"></a>

### 1.2. 误差到伪影的因果链

相位/波矢误差 → 频带错位与泄漏 → 重影/条纹 → 假结构。

低 SNR → Wiener 分母较小处的噪声放大 → 颗粒噪声/环状伪影。

样品运动 → 不同相位图不再对应同一对象 → 断裂、重复边缘和方向性伪影。

球差/折射率不匹配 → $H_{\mathrm{true}}\neq H_{\mathrm{calibrated}}$ → 轴向失真、对比度下降和频谱不连续。

<a id="s1-3"></a>

### 1.3. 评价不能只看“清晰度”

建议同时报告：

- 分辨率：FRC、decorrelation 或已知点/线结构的半峰全宽；
- 保真度：与物理参考或高 SNR 参考比较；
- SNR/PSNR/SSIM：只能作为辅助，不能单独证明真实超分辨；
- 频谱覆盖：是否真的恢复了预期的高频区域；
- 伪影率：条纹、重影、环状结构和负值比例；
- 定量任务误差：例如点间距、线宽、定位偏差、强度比；
- 不确定度：网络输出或重建参数变化下的结果方差。

同一数据应做以下对照：宽场、传统 Wiener、迭代物理法、深度学习法，以及仿真真值。尤其要避免用“经过同一网络生成的伪 GT”作为唯一证据。
