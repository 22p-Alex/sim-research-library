## 1. 推荐的毕业课题技术路线

<a id="s1-1"></a>

### 1.1. 阶段 A：建立可复现物理基线

1. 跑通当前 [3D-MP-SIM 主流程](../3D-MP-SIM/MP-main/core/Main_recon_MP.py)。
2. 保存每个样本的原始帧、OTF、`PGxy`、`PGz`、`cfai`、Wiener 参数和重建结果。
3. 用同一批数据比较宽场、Wiener、HiFi/陷波、迭代正则化结果。
4. 做参数扰动实验：
   $$
   \Delta\phi,\quad \Delta\mathbf k,\quad \Delta w,\quad \Delta\mathrm{SNR},\quad \Delta z.
   $$
5. 建立“参数误差 - 伪影 - 指标”的基线曲线。

<a id="s1-2"></a>

### 1.2. 阶段 B：做可解释的深度学习模块

推荐首个可落地课题：

> 输入：低 SNR 多帧 SIM + 物理 Wiener 初始重建 + 参数/OTF 先验。
> 输出：去噪且物理一致的超分辨结果或重建残差。

网络可以先采用 U-Net/Residual U-Net，目标不是替代物理模型，而是学习

$$
 r= x_{ref}-x_{Wiener},
 \qquad \hat x=x_{Wiener}+f_\psi(y,x_{Wiener},H,\hat\theta).
$$

这样保留了传统重建的可追溯性，网络只承担 Wiener 难以处理的噪声和系统残差。

<a id="s1-3"></a>

### 1.3. 阶段 C：引入物理一致性与不确定度

加入数据一致性层或可微前向模型：

$$
 y_{pred}=\mathbf A(\hat\theta)\hat x,
 \qquad
 \mathcal L_{data}=\|y_{pred}-y\|.
$$

再通过深度集成、Monte Carlo dropout 或 Bayesian 网络估计

$$
 \mathrm{Var}\big[\hat x(\mathbf r)\big]
 $$

把“网络不确定的位置”标出来。对于生物定量分析，给出不确定度通常比只给一张更锐利的图更有说服力。

<a id="s1-4"></a>

### 1.4. 阶段 D：严格验证

测试集必须按 **样品/实验批次** 划分，而不是随机切块：

- 训练：样品 A、B 的部分视野；
- 验证：样品 C；
- 测试：全新的样品、SNR、照明相位误差和像差条件。

必须做以下消融：

1. 仅网络 vs 物理 Wiener + 网络；
2. 无 `OTF`/参数输入 vs 有物理先验；
3. 无数据一致性损失 vs 有数据一致性损失；
4. 真实噪声 vs 合成噪声训练；
5. 不同网络容量和不同 Wiener 参数。

## 2. 现有代码与理论的映射

下表路径相对于 [MP-main 代码目录](../3D-MP-SIM/MP-main/)；运行环境见其 [README](../3D-MP-SIM/MP-main/README.md)。

| 理论步骤 | 代码位置 | 说明 |
|---|---|---|
| 原始 TIFF 加载、重排 | `core/DataProcess.py` | `load_RAW_DATA`、`Transfer2NPD` |
| Z 填充与窗函数 | `core/DataProcess.py` | `Image_zpadding`、`windows` |
| OTF 加载和 mask | `core/DataProcess.py` | `load_OTF`、`generatemask` |
| 相移矩阵/频带分离 | `core/Seperate_CK.py` | `SepMatrix5`、`separate_step_one` |
| 波矢/相位估计 | `core/Para_Estimate.py` | `parameter_estimationP2`、`parameter_estimation3` 等 |
| 频谱移位 | `core/Wiener_Reconstruction.py` | `IrTEST`、`_move_spectrum` |
| Wiener 分子分母 | `core/Wiener_Reconstruction.py` | `FZall`、`FZotf` 和后续融合函数 |
| 主流程编排 | `core/Main_recon_MP.py` | 加载、估计、分离和重建的总调度 |

当前代码对课题最有价值的中间量不是只有 `Wiener_results.tif`，还包括：

$$
 \{D_k, C_k, \mathbf k, \phi, m, H, M_{Wiener}, \hat x\}.
$$

这些中间量可以直接成为深度学习的监督标签、输入通道或物理一致性检查对象。

2D-SIM（单层 Wiener-SIM）的逐步代码对照不在此表，见[专题 03 第 3 节](03-传统重建与参数估计.md#s3)与 [fairSIM 理解笔记](../Wiener-SIM/fairSIM-论文/理解笔记.md)；fairSIM 源码位于 [`Wiener-SIM/fairSIM-src/fairSIM`](../Wiener-SIM/fairSIM-src/README.md)，关键入口为 `fiji/StepByStep.java`、`sim_algorithm/SimAlgorithm.java`、`sim_algorithm/Correlation.java`、`sim_algorithm/WienerFilter.java`。

## 3. 算法选择速查表

| 场景 | 首选 | 备选 | 主要注意 |
|---|---|---|---|
| 固定样品、高 SNR、追求细节 | HiFi/Wiener + 适度正则 | MRA、Sparse | 防止过度锐化 |
| 活细胞、低光、快速 | GPU Wiener/SDR + 轻量去噪网络 | Hessian/Sparse | 运动和漂白比网络大小更关键 |
| 厚样品、离焦明显 | 3D-SIM/OS-SIM、真实 3D OTF | blind-SIM、AO | 2D OTF 不能冒充真实 3D 重建 |
| 照明参数漂移 | 在线 PCA/相关估计 | blind-SIM | 不能长期复用过期参数 |
| 相位和波矢未知或畸变 | blind-SIM 或联合参数估计 | 物理约束 DL | 计算代价和可辨识性 |
| 需要深度学习创新 | Wiener 初值 + 残差/数据一致性网络 | 端到端网络 | 必须做物理和跨样品泛化验证 |

## 4. 统一待办清单

按依赖关系推进；每项完成后在条目下附实验记录、数据入口和配置。以下均沿用待完成状态。

### P0 · 先跑通物理基线

- [ ] **最小复现**：运行 MP-main 最小实例，保存 raw、OTF、重建结果、代码版本、参数及随机种子。
- [ ] **2D 基线对照**：用 fairSIM（S11，已克隆到 `Wiener-SIM/fairSIM-src/`）在同一组单层数据上跑一次 2D-SIM，记录其估计出的 cycle/µm、角度、相位、调制度与 Wiener/衰减/切趾参数，作为 MP-main 结果与教学模型的对照锚点；尚未在本机构建运行。
- [ ] **模型与维度核验**：在[已有 7 级频谱推导](04-三维SIM与多平面成像.md#s3)基础上，对照 S10 的 SI 和代码核验 5+5、`sequence=55`、频带含义与张量维度，形成逐项对照表。
- [ ] **可控仿真**：建立 3D-MP-SIM 合成数据生成器，控制波矢、相位、调制度、OTF、轴向间距和 Poisson/sCMOS 噪声，输出参数扰动与伪影的关系曲线。
- [ ] **统一 benchmark**：在适配各自采集模型的数据上比较宽场、Wiener、Open-3DSIM、MP 重建，以及 HiFi/陷波、Hessian/Sparse；记录分辨率、SNR、伪影、数据一致性、运行时间和显存。

### P1 · 建立并验证学习方案

- [ ] **物理初值 + 残差网络**：实现残差 U-Net 与数据一致性损失，对照传统基线、纯网络、无物理参数输入和无一致性损失等消融。
- [ ] **可复现与泛化评价**：记录每次实验的版本、参数、随机种子、样品/批次划分；检验真实/合成噪声、网络容量和 Wiener 参数的影响。
- [ ] **可靠性评价**：加入 MC dropout/深度集成或 Bayesian DL，做不确定性校准与跨样品评价，并关联物理残差和重建误差。

### P2 · 根据基线结果扩展

- [ ] **像差补偿**：评估 DeAbe 类方法对 SIM 条纹相位、调制度和频带分离的影响。
- [ ] **参数自适应**：复现 RL-SIM 的 APCOnly、RLOnly、APCRL 消融，区分物理约束与策略控制的贡献。
- [ ] **文献补充**：阅读 DMF-SIM，核对方法、实验和适用边界后再纳入知识结论。
- [ ] **证据索引**：从 S1 参考文献建立“算法—论文—代码—数据”四元表，登记已用与待复现资源。

## 5. 方法与课题角色对照

| 方法/资料 | 主要解决问题 | 物理位置 | 是否依赖 GT | 对本课题的角色 |
|---|---|---|---|---|
| Wiener/FDR | 基础频谱分离与融合 | 重建核心 | 否 | 最小可复现基线 |
| fairSIM（S11） | 2D-SIM 完整工程流水线：预处理、自动参数估计、Wiener 融合与诊断输出 | 开源参考实现（Java/ImageJ） | 否 | 代码级基线与教学模型校验基准 |
| HiFi-SIM | 2D 频谱接缝、PSF 旁瓣和伪影 | 频谱/PSF 工程 | 否 | 2D 高保真基线 |
| Open-3DSIM | 通用多层 3D-SIM、参数估计和滤波 | 3D 频域重建 | 否 | 3D-SIM 对照基线 |
| 3D-MP-SIM | 多平面快速 3D-SR | 采集模型 + 7 级频谱重建 | 否 | 当前课题核心物理模型 |
| DeAbe | 像差导致的 PSF/OTF 退化 | 重建前 PSF 补偿 | 通常需要合成/配对训练 | 像差前置校正模块 |
| SSR-SIM | 缺少 GT 时的自监督重建 | 采集策略 + 网络训练 | 不需要外部 GT | 低光、活细胞自监督模块 |
| BayesDL-SIM | 模型/数据不确定性和 KIC | 网络输出与后验 | 需要训练数据/参考评价 | 可靠性模块 |
| RL-SIM | 训练阶段照明参数自适应 | 训练闭环/策略控制 | 论文条件下使用 GT 派生量 | 参数自适应扩展方向 |
| DMF-SIM | 双模型重建与去噪 | 待阅读 | 待核对 | 后续文献补充 |
