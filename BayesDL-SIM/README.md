# BayesDL-SIM 文献条目

## 文献

Liu, Tao; Liu, Jiahao; Li, Dong; Tan, Shan. “Bayesian deep-learning structured illumination microscopy enables reliable super-resolution imaging with uncertainty quantification.” *Nature Communications*, 16, 5027 (2025). DOI: [10.1038/s41467-025-60093-w](https://doi.org/10.1038/s41467-025-60093-w).

## 文件说明

- 原文 PDF：论文发表版本的本地副本。
- `BayesDL-SIM-SI.pdf`：Supplementary Information 的本地副本。
- `metadata.yaml`：文献元数据、关键词、数据集和代码来源。
- `citation.bib`：BibTeX 引用条目。
- `中文译文.md`：按原文主文结构整理的中文工作译稿。公式使用 `$...$` 和 `$$...$$`，可由项目脚本生成 KaTeX 预览。
- `理解笔记.md`：面向“SIM + 深度学习”毕业课题的概念拆解、理论推导和实验建议。
- `中文译文预览.html`：由 `scripts/build_sim_preview.mjs` 生成的本地阅读页面。
